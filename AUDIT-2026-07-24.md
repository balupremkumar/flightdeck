## Phase 1 — Critical bugs (the ones Balu hit; one small batch)

### 1.1 "Reveal in Explorer" dead on repeat for the same file — HIGH, root-caused
Not a frontend bug: all six call sites call `revealItemInDir` fresh with no caching or guards
(`src/Explorer.tsx:426`, `src/PaneView.tsx:257` and `:498`, `src/LeftPanel.tsx:310`, `src/Settings.tsx:1234`, `src/Terminal.tsx:63`).
Root cause is in `tauri-plugin-opener` v2.5.4's Windows path (`reveal_item_in_dir.rs:110-170`): it uses Win32 `SHOpenFolderAndSelectItems`, and after the user closes the Explorer window, the shell's window-cache entry for that item lingers; a second reveal of the SAME item "activates" the dead window and returns success, so nothing opens and no error surfaces.
A different file is a different cache key, which is exactly the observed repro.
Fix: small custom Rust command spawning a fresh `explorer.exe /select,"<path>"` per call; route all six call sites through it.

### 1.2 Opening files from Explorer/Review does nothing — HIGH, root-caused
"Can't open certain files" is actually can't open ANY file: `open_path` is not part of `opener:default`, and `opener:allow-open-path` is granted nowhere (`src-tauri/capabilities/default.json:8`).
Every open is rejected by the Tauri ACL before Rust runs.
Explorer swallows the error (`src/Explorer.tsx:461` empty catch); Review shows "Couldn't open that file" every time (`src/Review.tsx:393`).
Fix: add `opener:allow-open-path` to the capability file (one line); also stop swallowing the Explorer error.

### 1.3 Explorer can show the WRONG worktree's contents — HIGH
Tree nodes are keyed by `name` not `path` (`src/Explorer.tsx:452`, `:191`), and a node's children effect doesn't depend on `path` (`:136-142`).
Flipping the Workspace/Pane scope toggle reuses same-named nodes (a worktree mirrors the checkout), so expanded folders keep the OLD root's children under the new root.
Correctness bug, not just staleness.
Fix: key nodes by `path`.

## Phase 5 — Premium demo video plan

Plan (keeps the real-UI authenticity, adds the cinema):
1. **Capture engine**: deterministic virtual-clock frame stepping — screenshot every 1/60s of a scripted timeline at 2x device scale, assemble with ffmpeg into a 2880x1800 master, ship 1440p60. Marries `reel.js`'s deterministic seekable-timeline pattern with `walkthrough.mjs`'s real-UI + mock-bridge approach. Every frame tack-sharp, butter motion, fully re-recordable in one command.
2. **Camera rig**: scripted push-ins and pans (transform on the app root), spotlight dim on the feature being demonstrated, subtle vignette; every scene gets exactly one camera move.
3. **Brand motion**: animated Deep Cove gradient title card with the wing mark, lower-third captions instead of the full-width bar, scene transitions, end card (logo, "Local-first. No account.", URL).
4. **Cursor + keys as actors**: bezier-eased cursor with overshoot, click ripples, keycap chips when shortcuts fire (Ctrl+Shift+A).
5. **Story, 60-75s**: hook ("Six agents. One screen."), workspace setup beat, parallel-work montage with time-lapse feel, the attention-queue moment, the review/split-diff/merge money shot, board dispatch, close. Mock transcripts rewritten to look genuinely like Claude/agy output with believable diffs and repo names.
6. **Audio**: royalty-free music bed; optional voiceover via voice-dictation's qwentts.cpp cloned voice (own-stack story) or music-only; subtle click ticks.
7. **Deliverables**: hero cut (MP4 H.264 + webm) for the kove page, four 10-15s silent feature loops for page sections, poster frame, README gif.
8. **QA gate**: `_frames.mjs` frame review + design-critique pass before anything ships; the old `reel.html` stays retired.
