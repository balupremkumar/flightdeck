# Flightdeck demo reel

`reel.html` is a standalone, self-contained motion-graphics recreation of the Flightdeck cockpit (Deep Cove theme) — autoplays on load, no build step, no dependency on the running app.

To re-record: `npm install`, `npx playwright install chromium`, then `npm run record`. The rendered video lands at `out/flightdeck-demo.webm`.
