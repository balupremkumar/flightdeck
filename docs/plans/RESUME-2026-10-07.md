## Lessons

- Agents: node_modules via a junction (`fs.symlinkSync(t, p, "junction")` or `mklink /J`), never `ln -s` in Git Bash.
- Live harness: never CDP Input on panes; synthetic events only; fgwatch guard on every run (off only for drops that open windows).
- `boot()` reloads the page after launch; on a saved session that reload lands while the restore prompt is open. Use `launchNoReload()` (w3-lib.mjs) for restore checks.
- `plugin:window|close` from page JS does nothing here; use `closehwnd` (window.ps1, WM_CLOSE).
- Never type `/focus` in a live Claude pane on Balu's machine.
