**The updater is now safe to trust, which it was NOT before.** The installer agent found six silent failure modes, the worst being that the installer was launched BEFORE the app had exited — only PowerShell's ~300ms startup separated them, so the update could fail because Flightdeck still held its own exe open. The watcher now waits for the PID to die (45s cap) and aborts with a message box rather than half-installing. A real bug was caught only by running the generated watcher end to end: PowerShell 5.1's `Set-Content -Encoding UTF8` writes a BOM and serde_json rejects it, so the whole failure-reporting feature would have silently done nothing. `release.ps1` now verifies its own output (size, MZ header, VERSIONINFO, manifest agreement, sha256) and reports the unsigned status loudly.
**Signing: docs/SIGNING.md, honest version.** SmartScreen is mostly NOT the current blocker (a locally built installer carries no Mark-of-the-Web); Defender AV heuristics on an unknown unsigned silent installer are. Self-signed is worthless here. OV/EV/Azure Trusted Signing costs are stated as shapes, not invented quotes. Balu's spend decision.

## v0.4.1 (superseded once the re-cut lands, 2026-08-01)
Fable's architectural review found a real defect in 0.4.0 and it was re-cut. **Do not install 0.4.0.**
FINDING (fixed, 9e713d2): previewed markdown is untrusted input (any cloned repo's README) and `isExternalHref` matched ANY scheme — so `javascript:`, `file:`, custom protocol handlers, and Windows drive-absolute paths (`c:` is a valid scheme shape) were all passed to `openUrl`, i.e. the OS shell.
